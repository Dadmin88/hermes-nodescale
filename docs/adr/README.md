# Architecture Decision Records

This directory records durable architectural decisions for Nodescale. ADRs describe the problem, the chosen contract, its consequences, and important rejected alternatives.

Implementation task status, milestone completion, checkpoint hashes, and agent handoff notes do not belong in ADRs unless they are necessary context for the architectural decision itself.
